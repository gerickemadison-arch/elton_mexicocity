# Wordmark

The name set as the mark: Elton ★ John in Shrikhand, `text` on `ground`, with a `star` star. This is the only logo until a drawn one exists.

- **Inline** for headers, social posts and anything wider than it is tall.
- **Stacked** for the poster and the invitation front. The star hangs top-right of *Elton*.
- The star is 50% of the cap height inline and 36% stacked, always `star`.
- Clear space is one star-height on every side. Minimum width is 120px on screen or 1.25in in print.
- On cream stock the type turns `stock-ink`. The star stays gold only when foil-stamped; otherwise it is lapel too.
- Never outline it, add a shadow or set it in caps.
