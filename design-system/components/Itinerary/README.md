# Itinerary

The weekend schedule: a satin band, a headline, the stops, and one sunburst stop for the main event.

- Start with the satin band, then an eyebrow (city and dates), a Shrikhand `headline` and an optional `aside` in `spark`.
- Each stop row has a `label` time column (104px) and the event as an `event-name` in `text` over a `detail` in `text-second`. Rows are divided by `seam` hairlines.
- **The sunburst stop marks the concert only.** It's `ray` gold on `ground-deep` behind a cream ticket (see Ticket). Use one per itinerary, never more.
- The `aside` counts as this piece's one pink moment. For an after-party column, use the Star Glasses accent instead.
- The venues and times in the preview are sample content.
