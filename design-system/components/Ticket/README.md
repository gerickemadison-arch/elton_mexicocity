# Ticket

A cream ticket with cut corners and lapel text, used for the featured event, drink tickets and place cards.

- The corners are cut at `notch` (12px), never rounded.
- The only text colour is `stock-ink`, because gold and pink never sit on cream. Tickets look the same in both themes; only the ground around them changes.
- Top to bottom: `eyebrow` (day and time), the title, an optional `detail` line, and a `fine` stub below a dashed rule.
- The featured title is Shrikhand (`ticket-title`). Smaller tickets use the italic accent for the title.
- Centre the text inside a ticket; it's the one place the system centres.
