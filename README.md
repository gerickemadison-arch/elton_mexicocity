# Elton John Mexico City

The approved design system for an Elton John night in Mexico City.

- Live design system: https://claude.ai/artifact/9WDHLQMJk9TwqKkyGvgbTF
- `design-system/README.md`: the brand book (colour, type, lockup, signature elements, layout, voice, production notes)
- `design-system/tokens.json`: colour (Lapel main theme and Star Glasses accent theme), type, spacing, radius and stripe tokens
- `design-system/components/`: Wordmark, Ticket, Itinerary, Star Glasses accent and the cover, as HTML previews with usage notes
- `design-system/fonts/`: Shrikhand, Josefin Sans and Cormorant Garamond Medium Italic (SIL Open Font License, via Google Fonts)

The moodboard images live in the design system artifact only; they are reference material, not for publishing.
